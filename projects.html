[ P / 01 ] // UNITY 3D · C#

Cobra Card Game

Cobra Card Game is a competitive multiplayer card title engineered around deterministic systems. Rather than relying on simple procedural logic, every single phase of play — dealing animations, client hand evaluation, turn progression, and final point calculation — is coordinated through formal explicit state machines.

The presentation layer runs on Unity's high-performance UI Toolkit setup, integrated with a deeply tuned DOTween animation pipeline. Card trajectories, hand fan layouts, and table physics maintain a tactile 60 FPS response, guaranteeing that matches remain completely synchronized as the table scales.

[ P / 02 ] // REAL-TIME MULTIPLAYER

Online Chess Game

An online competitive multiplayer chess platform developed in Unity featuring synchronized gameplay, player statistics databases, token and cosmetic systems, and custom AI behavior modes for offline practice.

The chess engine implements complete FIDE-compliant rules, including en passant, castling, pawn promotion, legal move calculation, check/checkmate verification, and stalemates. The netcode is engineered with an authoritative state architecture, ensuring latency does not desynchronize the board.

[ P / 03 ] // CASINO LOGIC & PROBABILITY

Digital Blackjack

A high-fidelity implementation of the classic casino card game, engineered with rigorous probability mathematics and fair deck-shuffling algorithms. The engine eschews black-box randomness in favor of deterministic Fisher-Yates multi-deck shoes and real-time dealer bust probability calculations.

The UI is optimized for desktop and WebGL deployment, presenting players with clean telemetry, split-hand tracking, double-down logic, and insurance payouts in an elegant, distraction-free environment.

[ P / 04 ] // RETRO ARCHITECTURE

Java Desktop Games Collection

A retrospective collection of arcade classics engineered from the ground up in Java — Snake, Breakout, Pac-Man, and Sokoban — alongside an original custom puzzle title.

Every game in the suite is implemented as a pure, self-contained Java Swing application with zero third-party game frameworks. This deliberate constraint emphasizes mastery of core computer science fundamentals: tick-rate loop timing, double buffering, hardware keyboard input polling, and efficient 2D collision quadtrees.

[ P / 05 ] // MACHINE LEARNING & TELEMETRY

AI Crop Recommendation System

An intelligent agricultural prediction system designed to assist farmers by recommending the highest-yielding crops based on real-time ecological data. The system aggregates three dynamic data feeds: soil nutrient analysis (NPK, pH), GPS location coordinates, and live meteorological weather APIs (precipitation, temperature, humidity).

The underlying intelligence is driven by a Random Forest Classifier trained using Scikit-learn. The ensemble model provides superior accuracy over single decision trees while remaining fully explainable through feature importance metrics.

[ P / 06 ] // COMPUTER VISION & ROBOTICS

Vision-Based Robotic Teleoperation

A high-precision human-machine interface that translates complex hand gestures — including structured sign-language alphabets and custom spatial controls — into real-time physical robotic arm motions.

The computer vision pipeline processes continuous video streams through OpenCV, extracting 21 anatomical landmarks per hand. These landmarks are normalized and classified, then mapped via inverse kinematics algorithms to robotic end-effector coordinates. Engineered with an emphasis on low latency, the system allows operator teleoperation with natural proprioceptive feedback.
